# Управление базой данных СТО (C# / WPF)

Десктопное приложение для автоматизации учета заказов на станции технического обслуживания (СТО).

## Основной функционал

**Просмотр заказов:** Вывод заказов на экран с объединением данных из 4-х таблиц и расчетом итоговой стоимости.
**Добавление заказов:** Выбор даты, автомобиля, мастера и множественный выбор услуг (ListBox с CheckBox).
**Редактирование:** Изменение данных заказа и связанных услуг.
**Удаление:** Удаление заказов с очисткой связанных таблиц.

## Технологии

* C# (.NET Framework 4.8.1)
* WPF
* MS Access (OleDb / ADO.NET)
